# code/scout: derived numbers and figures for the Willow manuscript

These are the Willow sections of the workspace's `code/scout/README.md`; its QRC scripts are not in this
repository. Run every command from the workspace root with `OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1
MKL_NUM_THREADS=1 NUMBA_NUM_THREADS=1`. Paths are built from each script's own location (`code/scout/../..`).

- `ml_dp.py` and `xcheck_decoder_bundle.py`: an independent exact-ML cross-check of decoder's error-correction
  code (results in `results/scout/xcheck_d*.json`).
